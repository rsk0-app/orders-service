# orders-service

A small Go HTTP service managing order lifecycle (create, get, mark-shipped).

## Run

```bash
go run .
# http://localhost:8080/healthz
```

## Routes

- `GET  /healthz`
- `POST /orders`
- `GET  /orders/{id}`
